Brave installation: Start START_SERVER.bat; leave open. Open brave://extensions in each profile, enable Developer mode, Load unpacked, select this folder. Restart the server after upgrading (Ctrl+C then START_SERVER.bat). Use saved names: one FULL name per line; the extension now prefers the list automatically when present. Phone: reserved UK/US test numbers where supported; for other countries enter a phone number you control. Shared SQLite history prevents reuse. The extension does not submit forms.
